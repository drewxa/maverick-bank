# Changelog

## 0.1.0 — release candidate — 2026-11-01

- Local Markdown memory shared through a CLI and MCP server, with configurable scopes, sources, record status and superseding corrections.
- SQLite full-text retrieval and optional explicitly provisioned local multilingual semantic retrieval.
- Local Git snapshots in an isolated sidecar repository; durable access and operation journals separate from the rebuildable index.
- Codex and Claude Code configuration adapters with ownership tracking, backups and data-preserving removal.
- Scoped, paginated audits with dataset revisions and periodic local structural-check hints; no automatic truth verification or edits.
- Startup loading of configured capture policy, owned-registration diagnostics and explicit interrupted-capture recovery preserving human edits.
- Usage statistics distinguishing offered excerpts, served reads and agent-declared use.
- Installation scripts, configuration/privacy/recovery documentation and release verification checklist.

This is a candidate description, not a claim that every target platform and authenticated host trial has passed. See [validation evidence](docs/VALIDATION.md) for actual checks and limitations. No public registry publication is included.
